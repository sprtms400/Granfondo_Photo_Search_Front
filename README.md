# Granfondo Photo Search — 웹 화면

마라톤·그란폰도 대회 사진 검색 서비스의 사용자 화면이다. Vue 로 만들었다.

> 2024년 작업이다. 서버 쪽은 [Granfondo_Photo_Search](https://github.com/sprtms400/Granfondo_Photo_Search) 에 있다.

---

# 개요

## 1. 어떤 문제를 해결하려 했나요?

사진에 꼬리표를 붙이고 검색 API 를 만들어도, 참가자가 그걸 쓰려면 화면이 있어야 한다. 대회에 나온 사람들이 API 를 직접 부를 리는 없다.

## 2. 어떻게 되었나요

검색창에 옷차림을 적으면 사진이 나오는 화면을 만들었다. 대회를 고르고, 검색어를 넣고, 결과를 격자로 보고, 하나를 누르면 원본과 분석 결과를 함께 볼 수 있다.

## 3. 향후 과제

대회 목록이 늘어났을 때의 화면 구성, 그리고 배번호 검색이 서버에 붙으면 그에 맞는 입력 방식이 필요하다.

# 상세

## 1. 기존 문제 설정

검색 결과가 사진이라는 게 화면 설계의 어려움이었다.

한 번에 수십 장이 나오는데 전부 큰 이미지다. 그대로 다 불러오면 느리고, 너무 줄이면 자기 사진인지 알아볼 수 없다. 그리고 사진을 눌렀을 때 "왜 이게 검색됐는지"를 보여줘야 사용자가 검색어를 고칠 수 있다.

## 2. 해결방안 제시

**결과는 격자로, 상세는 모달로.** 목록에서는 작게 여러 장을 보여주고, 누르면 그 자리에서 큰 이미지와 분석 결과가 뜨게 했다. 페이지를 옮기지 않으니 목록으로 돌아오기 쉽다.

**분석 결과를 같이 보여준다.** 이 사진에서 어떤 옷차림을 읽어냈는지 표시하면, 사용자가 "아 색을 다르게 적어야겠다" 를 스스로 판단할 수 있다.

## 3. 구현 상세

### 화면 구성

| 컴포넌트 | 하는 일 |
|---|---|
| `SearchForm` | 대회 선택과 검색어 입력 |
| `SearchResults` | 검색 결과를 격자로 나열 |
| `DetailModal` | 사진을 눌렀을 때 뜨는 상세 창 |
| `PhotoDetails` | 원본 이미지와 분석된 옷차림 정보 |

### 데이터 처리

| 서비스 | 하는 일 |
|---|---|
| `searchService` | 검색 API 호출 |
| `compManager` | 대회 목록 관리 |
| `photoManager` | 사진 데이터 관리 |
| `vuexStore` | 화면 간 공유 상태 |

### 실행

```
nvm install 20.11
npm install -g yarn @vue/cli
yarn install
vue serve
```

Ubuntu 20.04, Node 20.11 에서 개발했다.

## 4. 한계점

- 대회가 하나뿐일 때를 전제로 만들어서, 목록이 길어지면 선택 화면을 다시 짜야 한다.
- 배번호 검색 입력이 없다. 서버에 그 기능이 아직 붙어 있지 않아서다.
- 결과 이미지에 지연 로딩이나 썸네일 처리가 없다. 결과가 많으면 느려진다.
- 테스트 코드가 없다.
